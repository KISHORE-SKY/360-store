Project Name:
360-Store
  
  360-store is a modern e-commerce web application built with React. It provides a seamless shopping experience with essential         features like product browsing, cart management, and user authentication.
  The project focuses on building a clean UI, smooth navigation, and scalable frontend architecture.


Features:
Cart Management  
  Add items to cart and remove them easily

Authentication (Login / Signup)  
  User data is stored in localStorage

Protected Routes 
  Private routes (e.g., admin) accessible only to authenticated users

Public Routes  
  Open product listing page for all users


Tech Stacks:
React JS
Tailwind CSS
React Redux
React Router
MUI
